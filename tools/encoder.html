MCImage encoder

Turn any picture into /mcimage commands. Everything happens in your browser - nothing is uploaded anywhere.

1. Pick an image

Drop an image here, click to browse, or paste one with Ctrl+V / Cmd+V
PNG, JPEG, GIF, BMP, WebP - it will be resized to 128x128 (one map)

Smaller is better: every ~247 characters is one chat message. Lower the JPEG quality, or use crop for a square cut-out, to need fewer parts.

4. Paste into Minecraft chat, one command at a time

  1. Click Copy next (or the copy button of a line), press T in game, paste with Ctrl+V, press Enter.
  2. Repeat until the last line (/mcimage done) - the plugin joins the parts and hands you the map.
  3. Lost track? /mcimage status shows how many parts arrived, /mcimage cancel starts over.

Alternative: one single command

The server accepts commands up to 32,767 characters, but the vanilla chat box stops at 256. Use this from the server console (without the leading slash), a command block, RCON, or a client mod that lifts the chat limit.
